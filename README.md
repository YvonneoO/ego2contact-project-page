# Ego2Contact — project page

Project page for **Ego2Contact: Predicting Touch from Egocentric Human Video for Contact-Rich Robot Manipulation**.

The page is static: `index.html` plus media in `assets/`. It is generated from the paper's figures and result media with the build
scripts kept alongside the paper sources (`webpage/build/build_page.py --public`), so edit the generator rather than this HTML.
